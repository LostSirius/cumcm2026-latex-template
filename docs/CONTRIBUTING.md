# 贡献指南

欢迎提交可复现的排版修复、跨平台兼容改进和文档勘误。

提交前请确认：

1. 变更依据来自全国组委会官网或可核验的赛区通知，并在说明中附链接。
2. 不提交真实参赛论文、未公开赛题讨论、队员信息或学校信息。
3. 不上传编译缓存、包含身份信息的 PDF、办公文档元数据或截图。
4. `paper.tex` 与 `templates/AI工具使用详情.tex` 均可用 XeLaTeX 编译。
5. 不改变电子版默认的 `withoutpreface` 设置。
6. 不在未获上游授权的情况下新增许可证声明。

本项目只处理排版与规范呈现问题，不接受竞赛期间涉及赛题求解、模型内容或答案交流的提交。
